# CineApp

**Nome:** RICARDO NOBUO SUGANO
**RA:** 2991392513008

## Descrição

O CineApp é um aplicativo de catálogo de filmes feito com React Native e Expo para a disciplina de Programação para Dispositivos Móveis I. Ele tem uma tela inicial, uma lista com 6 filmes onde dá para marcar favoritos, uma tela de detalhes de cada filme e uma tela com informações sobre o app.

## Como executar

```
npm install
npx expo start
```

Depois é só abrir no Expo Go pelo QR Code ou em um emulador.
